# ROOMFIT

내 방 설계를 도와주는 반응형 웹사이트입니다.

## GitHub Pages 배포
1. ZIP 압축을 풉니다.
2. index.html, style.css, app.js, assets 폴더를 저장소 최상위에 업로드합니다.
3. Settings > Pages에서 Deploy from a branch를 선택합니다.
4. main 브랜치와 /(root)를 선택하고 저장합니다.

별도 빌드나 패키지 설치가 필요하지 않습니다. assets 폴더 구조를 유지해주세요.
설계보드와 저장한 가구는 사용 중인 브라우저의 로컬 저장소에 보관됩니다.
최신 버전에는 소리 기능이 제거되어 있으며 기존 애니메이션과 설계 기능은 유지됩니다.
